# 日本动画制作公司 · 十年播放与口碑看板（2016–2025）

一个单文件交互看板：把 2016–2025 十年日本动画作品库按「制作公司 / 导演 / 原创-改编」三个切面聚合，同时看**平台播放量**与**国内口碑热度**两套指标。

## 指标定义

- **Netflix 观看小时**：来自 Netflix 官方 *What We Watched* 半年报（2023H2 / 2024H1 / 2024H2 / 2025H1 / 2025H2 共 5 期）逐条匹配后累加，单位为百万小时。
- **评分人数中位数**：Bangumi 用户评分人数，作为国内口碑热度的代理指标（不用平均分，避免小样本拉偏）。
- **续作率**：TV/WEB 作品中有 Bangumi 登记续作记录的比例，用作「是否被市场续订」的代理指标。
- **播放达标 / 口碑达标**：全库统一阈值——观看小时 P75 = 2.12 百万、P90 = 8.06 百万；评分人数 P75 = 3,448、P90 = 7,934。

## 三个必须注意的偏倚

1. **两指标相关性很弱**（全库 r = 0.185；2016–19 为 0.178，2020–25 为 0.211）。播放量与口碑热度基本是两条独立的轴，不存在「叫好又叫座」的稳定规律。
2. **Netflix 覆盖率只有 19.2%，且逐年后移**（2016 年仅 6.5%，2025 显著更高）。所以**不能跨年段比较绝对小时数**——覆盖率差异会直接伪装成「行业增长」。
3. **原创被平台收录的比例远低于改编**（7.0% vs 24.3%），播放达标率的差距大半是平台筛选造成的。本数据只能支持「原创更难被看见」，**不支持**「原创质量更差」这种因果结论。

## 数据来源

- 作品元数据、评分、评分人数、关联关系：Bangumi（番组计划）公开数据
- 播放表现：Netflix 官方 Engagement Report（What We Watched，2023H2–2025H2）
- 日本票房：映连年度票房榜（10 亿日元以上）

样本：2016–2019 年 1,201 部，2020–2025 年 1,887 部，合计 3,088 部。
